# ADR-003. 4계절 분류 채택, 8세부 타입은 비목표

- **상태**: 채택
- **결정일**: 2026-08-07

---

## 맥락

원본 프로젝트는 웜/쿨 2분류였습니다. 보고서에 이유가 적혀 있습니다.

> 계절 안에서도 명채도로 세부 범위를 나눌 수 있지만 우리는 대부분의 사람들이 알고 있는 쿨톤과 웜톤으로만 분류하기로 했다.

재구축에서는 어디까지 갈지 정해야 합니다. 선택지는 셋입니다.

| | 클래스 수 | 필요한 축 |
|---|---|---|
| 웜/쿨 2분류 | 2 | 언더톤 |
| **4계절** | 4 | 언더톤 + 명도 |
| 8세부 타입 | 8 | 언더톤 + 명도 + 채도 + 대비 |

---

## 결정

**4계절을 채택합니다. 8세부 타입은 명시적 비목표입니다.**

### 4계절을 선택한 이유

**실용성이 급격히 올라갑니다.** "웜톤입니다"는 사용자가 다음에 뭘 해야 할지 알려주지 않습니다. 봄 웜과 가을 웜은 같은 웜톤이지만 추천 팔레트가 거의 겹치지 않습니다 — 봄에게 어울리는 코랄과 아이보리는 가을에게 얼굴을 붕 뜨게 만들고, 가을의 머스타드와 카키는 봄의 혈색을 눌러버립니다. 2분류의 결과물은 사실상 쓸모가 없습니다.

**측정 가능한 축이 실제로 두 개 있습니다.** 언더톤(`h°`)과 명도(`ITA°`)는 사진 한 장에서 독립적으로 뽑아낼 수 있는 신호입니다. 2분류는 이 중 하나를 버리는 셈입니다.

**보고서가 남긴 숙제입니다.** 원본이 "나눌 수 있지만 안 했다"고 적어둔 부분을 이번에 하는 것이 재구축의 서사와 맞습니다.

### 8세부 타입을 배제한 이유

봄 라이트/브라이트, 여름 라이트/뮤트, 가을 뮤트/딥, 겨울 브라이트/딥으로 나누는 방식입니다.

**첫째, 사진 한 장에서 뽑을 수 있는 독립 신호가 부족합니다.** 8분류는 최소 3~4개의 판별 축을 요구하는데, 우리가 가진 세 축조차 서로 상관되어 있습니다 (`b*`가 `h°`와 `ITA°` 양쪽 계산에 들어갑니다). 축을 억지로 늘리면 클래스 경계가 측정 노이즈 수준으로 얇아지고, 확률 분포가 8개 클래스에 고르게 퍼져 아무 정보도 전달하지 못합니다.

**둘째, 오프라인 진단에서도 세부 타입은 진단천 대비로 판정합니다.** 피부 절대 색상이 아니라 "이 천을 댔을 때 얼굴이 사는가"라는 관찰입니다. 우리 파이프라인에는 이에 대응하는 입력이 없습니다.

**셋째, 4계절도 아직 검증되지 않았습니다.** 4계절 정확도를 실측하기 전에 8분류로 확장하는 것은 검증되지 않은 기반 위에 층을 쌓는 것입니다.

---

## 대신 하는 것

세부 타입 대신 **세 축의 원시 측정값을 그대로 노출**합니다.

```
언더톤   쿨 ├──────────●───┤ 웜        h°   = 68.5
명도     딥 ├──●───────────┤ 라이트     ITA° = 13.8
선명도  뮤트 ├───────────●─┤ 클리어     C*   = 49.0
```

사용자는 "가을 웜"이라는 라벨과 함께 "웜 성향이 뚜렷하고, 명도는 깊은 쪽이며, 채도가 매우 높다"는 정보를 얻습니다. 이는 사실상 *가을 딥* 에 해당하는 정보지만, **우리가 검증하지 않은 라벨을 붙이지 않고** 관측값을 그대로 전달하는 형태입니다.

퍼스널 컬러에 익숙한 사용자는 이 세 게이지를 보고 스스로 세부 타입을 유추할 수 있습니다. 익숙하지 않은 사용자에게는 4계절 라벨과 팔레트만으로 충분합니다.

## 결과

### 얻는 것

- 실사용 가치가 있는 결과물 (계절별 팔레트가 실질적으로 다름)
- 프로토타입 기반 분류라 나중에 8타입 확장 시 **좌표만 추가**하면 됨 — 구조 변경 불필요
- 검증 가능한 범위를 유지 (200~300장 검증셋으로 4클래스는 클래스당 50~75장, 통계적으로 의미 있음)

### 치르는 비용

- 8타입을 기대한 사용자에게는 부족하게 느껴질 수 있음 → 세 축 게이지로 부분 보완
- 4클래스는 2클래스보다 정확도가 낮게 나옴 → 언더톤 신뢰도를 **별도로 보고**해 완화

---

## 확장 조건

다음이 모두 충족되면 8타입 확장을 재검토합니다.

1. 4계절 정확도가 수동 검증셋에서 70% 이상
2. 신뢰도 캘리브레이션 오차(ECE)가 0.1 이하
3. 세부 타입 라벨이 달린 검증 데이터를 확보
